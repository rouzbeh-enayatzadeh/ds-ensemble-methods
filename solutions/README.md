# Solutions

Reference solutions for the exercise notebooks in this repository. Open a solution alongside its source notebook to check your work.

| File / Folder | Description |
|---|---|
| [**2 - XGBoost**](2_applying_xgboost.ipynb) | Worked solution: load and split the diabetes data, train an `XGBClassifier`, evaluate it with a classification report and confusion matrix, then map the decision surface over a feature grid and plot it in 3D. |
| [**3 - Classification Comparison**](3_comparison_classification_algorithms_exercise.ipynb) | Worked solution for the CharityML census exercise: preprocessing (log transforms, one-hot encoding, scaling), a naive baseline, comparison of Decision Tree, SVM, and AdaBoost, then tuning the best model with `GridSearchCV` and a reduced-feature retrain. |
